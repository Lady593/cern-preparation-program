# CERN Preparation Program - Portafolio

## Objetivo personal
Fortalecer mis conocimientos y habilidades técnicas en el área de tecnologías de la información y el análisis de datos científicos, preparándome para aprovechar al máximo las herramientas y prácticas de investigación en entornos de computación científica como los del CERN.

## Tecnologías y áreas a fortalecer
* **Contenedorización y Entornos:** Docker, manejo de contenedores y terminales Linux (Bash/Root).
* **Control de Versiones:** Git y GitHub para la documentación de proyectos.
* **Análisis de Datos y Herramientas Científicas:** Exploración de datasets en el CERN Open Data Portal, Python y procesamiento de datos abiertos.
